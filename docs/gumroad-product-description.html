If GeForce NOW or Xbox Cloud Gaming stutters every few seconds on your Mac, AWDL is a common cause. Ping Warden keeps it switched off while you play.

What it fixes

AWDL is the wireless interface behind AirDrop, AirPlay, and Handoff, and on a lot of Macs it shows up as short lag spikes in a game stream. Running sudo ifconfig awdl0 down once doesn't keep it down, because macOS can raise the interface again whenever it wants. Ping Protection responds to interface-change events and lowers AWDL again for as long as protection is on, so you don't have to babysit a terminal window or a polling script.

The image above shows the same Mac and Wi-Fi network with Ping Protection off and on. Results vary by network, and Ping Warden doesn't fix every source of lag.

How it works

The dashboard is free. It shows your live ping, jitter, and latency spikes against public servers, your router, and the GeForce NOW regions it discovers. A one-time $15 license unlocks Ping Protection, including protected Latency Sessions. There's no subscription, and the license covers all future updates.

You can turn protection on from the menu bar, let Game Mode handle it, or add the native Ping Protection toggle to Control Center on macOS 26. You can pin that toggle to the menu bar and hide Ping Warden's own icon.

The tradeoff is that AirDrop, AirPlay, Handoff, and other AWDL features don't work while protection is on. Turn it off or pause it for 10 minutes when you need them.
